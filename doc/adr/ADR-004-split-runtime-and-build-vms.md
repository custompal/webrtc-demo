# ADR-004：改用单台大档云主机（编译 + 运行同机）

- 状态：Superseded（2026-09-10，原“分开两台”→“单台大档”）

## 背景
原方案为“运行机(腾讯轻量香港 2C2G ¥38/月) + 构建机(Hetzner SG 按时几小时)分开”，总花约 ¥42/周。用户为省去“编译机→运行机”拷贝部署的麻烦，改回单台大档同机编译 + 运行。

单台需同时满足：编译 libwebrtc Android（~50GB 磁盘 / 8GB+ RAM / 4-8 核 / 几小时）+ 跑 coturn/信令 + 公网 IP + 放行 UDP + 国内/香港低延迟。原 ¥50 预算扛不住，已提到约 ¥100-112/周。

## 决策
- 单台国内/香港大档云主机（~8C8G/100GB+，~¥100+/月），同机部署编译环境 + coturn + Go 信令。
- 候选：腾讯轻量/阿里轻量香港高档；或 Hetzner SG CPX32 按小时开一周(~¥112)。

## 后果
- 优点：编译 + 运行同机，省一台机器管理；后续改 libwebrtc 源码重编直接 SSH 上这台，无需另租构建机。
- 缺点：预算从 ~¥42 提到 ~¥100-112/周；编译时 CPU 占满会短暂影响 coturn/信令（学习 demo 可接受）。
- 澄清：libwebrtc 的 `.a/.so` + 头文件仍需 scp 回 Windows 链接进 Android app（Android 工具链在 Windows）。“省去拷贝部署”指 coturn/信令/编译环境同在一台，不再为运行单独租一台小机；编译产物回 Windows 是 Android 构建必须，不在此省。
- 风险：购买前确认厂商放行 UDP 3478 + relay 端口段（香港轻量一般可配，部分国内云默认限 UDP）。

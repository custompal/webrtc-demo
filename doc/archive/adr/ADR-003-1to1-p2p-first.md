# ADR-003：先做 1:1 P2P，不引入 SFU

- 状态：Accepted（2026-09-09）

## 背景
“发起会议 / 输入 ID 加入”的描述暗示多方。多方需要 SFU 媒体服务器，复杂度剧增，偏离“学 WebRTC 内部”重点。

## 决策
- 先实现 1:1 P2P（纯 P2P + TURN 兜底）。
- 会议 ID = 6 位随机码、无鉴权、上限 2 人。

## 后果
- 优点：聚焦 ICE / 穿透 / 媒体传输学习；服务器只需 STUN / TURN / 信令，无需 SFU。
- 缺点：不支持多方；后续若要多方需另引 SFU（mediasoup 等），属于新阶段。
- 扩展：后续可扩 mesh（2-3 人），仍以学 P2P 为主。
